# Ubuntu 字典软件 - 产品需求文档（PRD）

> 版本：v1.0
> 日期：2026-10-07
> 状态：设计阶段

## 1. 产品概述

### 1.1 产品名称
**UbDict**（Ubuntu Dictionary）—— 一款面向 Ubuntu 系统的智能英汉词典工具。

### 1.2 产品定位
一款轻量级、低打扰、即指即译的桌面词典，支持文本选词、图片取词（OCR）、第三方 PDF 阅读器悬停取词，翻译来源接入必应词典等来源。

### 1.3 目标用户
- Linux/Ubuntu 日常用户（学生、开发者、研究人员）
- 需要阅读英文 PDF 文档、网页、图片的技术人员
- 对翻译质量有要求，倾向权威词典源的用户

### 1.4 设计原则
| 原则 | 说明 |
|------|------|
| 即指即译 | 取词后自动弹出翻译窗口，无需手动触发 |
| 易读且低打扰 | 翻译窗口使用不透明背景；鼠标悬停时保持显示，离开后延迟自动消失 |
| 权威可信 | 翻译来源以必应词典为主，可扩展多源 |
| 覆盖全场景 | 文本/图片/PDF 三大场景统一体验 |
| 原生体验 | 遵循 GNOME/Ubuntu 人机交互指南（HIG） |

## 2. 功能需求

### 2.1 核心功能模块

```
┌─────────────────────────────────────────────┐
│              UbDict 功能架构                 │
├─────────────────────────────────────────────┤
│  F1 文本取词   F2 图片取词   F3 PDF取词      │
│  F4 翻译服务   F5 翻译窗口   F6 设置中心     │
│  F7 历史记录   F8 生词本     F9 全局热键     │
└─────────────────────────────────────────────┘
```

### 2.2 F1 - 文本取词

**触发方式**：鼠标选中文本（任意应用中的可选中文字）

**功能描述**：
- 用户在任意应用中用鼠标选中英文单词/短语
- 选中后延迟 300ms（避免误触发）自动弹出翻译窗口
- 翻译窗口显示在鼠标附近，不遮挡原文
- 支持单词、短语、短句（≤ 200 字符）

**实现机制**：
- 监听 X11/Wayland 全局剪贴板 Selection 事件（PRIMARY selection）
- 通过 `xclip` / `xsel` 或 Python `python-xlib` 获取选中文本
- Wayland 下通过 `wl-copy` 或文本协议扩展

**验收标准**：
- [ ] 在 Firefox/Chrome/终端/LibreOffice 中选词均可触发
- [ ] 选词到出窗延迟 ≤ 500ms
- [ ] 重复选同一词不重复请求翻译（缓存命中）

### 2.3 F2 - 图片取词（OCR）

**触发方式**：鼠标悬停在图片上的英文文字区域停留 ≥ 3 秒

**功能描述**：
- 鼠标在图片（或任意位图区域）上停留超过 3 秒
- 自动截取鼠标周围 200×80 像素区域
- OCR 识别该区域内的英文单词
- 识别成功后弹出翻译窗口

**实现机制**：
- 全局鼠标位置监听（`python-xlib` / `evdev`）
- 停留计时器：3 秒触发截图
- 截图：`grim`（Wayland）/ `scrot` / `mss`（X11）
- OCR 引擎：**Tesseract OCR**（`pytesseract`），英文模型 `eng.traineddata`
- 识别后取距离鼠标最近的单词

**性能要求**：
- OCR 单次识别 ≤ 800ms
- 鼠标移动时取消计时器，避免频繁触发
- 识别失败静默处理，不打扰用户

**验收标准**：
- [ ] 在图片查看器、浏览器图片、截图上均可取词
- [ ] 3 秒停留触发，移动鼠标重置计时
- [ ] OCR 准确率 ≥ 85%（清晰印刷体英文）

### 2.4 F3 - PDF 取词

**触发方式**：在任意第三方 PDF 阅读器中启用“PDF 悬停取词”，在英文上停留后由屏幕 OCR 识别；选中文本仍可使用 F1。

**功能描述**：
- 不要求在 UbDict 内打开 PDF，可使用 Evince、Okular、Firefox 等外部阅读器
- 鼠标悬停默认 3 秒后截取光标附近区域并 OCR
- PDF OCR 与图片 OCR 共用采样器，两个模式互斥
- Wayland 桌面必须允许应用获取全局鼠标坐标；GNOME Wayland 等未暴露此能力的桌面无法提供悬停 OCR

**验收标准**：
- [ ] 外部阅读器中的可识别英文可通过悬停 OCR 触发翻译
- [ ] 翻页后可继续取词
- [ ] 不支持全局鼠标坐标的平台明确提示限制

### 2.5 F4 - 翻译服务

**翻译来源**（按优先级）：

| 来源 | 用途 | 接入方式 |
|------|------|----------|
| **必应词典**（主） | 英汉互译、例句、发音 | Web API / 页面解析 |
| **有道词典**（备） | 补充释义、网络释义 | Web API |
| **本地词典**（离线） | 无网络时兜底 | StarDict/ECDICT SQLite |
| **DeepL**（可选） | 整句翻译 | 官方 API（需 Key） |

**翻译结果内容**：
- 音标（美音/英音）
- 词性 + 释义
- 例句（完整视图最多展示 10 条，实际数量取决于翻译来源）
- 发音音频（美音/英音，可播放）
- 词形变化（名词复数、动词时态等，如有）
- 必应词典提供时展示详细英汉释义、用法标记、搭配和反义词
- 主窗口展示当前翻译返回的完整释义、例句和词典来源；不伪造适配器未提供的文献数据

**容错策略**：
- 主源失败 → 自动降级到备用源
- 全部网络源失败 → 使用本地词典
- 本地词典也无 → 提示"未找到释义"

**验收标准**：
- [ ] 必应词典返回完整释义
- [ ] 网络断开时降级到本地词典
- [ ] 翻译结果缓存（LRU，1000 词）

### 2.6 F5 - 翻译窗口

**窗口特性**：
- 无边框、不透明背景、圆角
- 大小：360×420（可自适应内容）
- 位置：鼠标附近，智能避让屏幕边缘
- 鼠标悬停时保持显示；鼠标离开后约 8 秒自动关闭
- Esc 键关闭
- “在主窗口显示更多”按钮将当前结果展开到主窗口，不重复查询
- “加入生词本”按钮显示新增或重复添加状态
- 音标旁的扬声器按钮优先获取在线自然英语发音；仅使用直连 HTTPS（忽略系统代理），无网络、无音频或播放失败时回退到本地 espeak-ng

主窗口保留手动查询和历史记录；对于必应词条显示简明释义、详细英汉释义、例句、词形、常用搭配、反义词、音标及词典来源。当前翻译数据模型不含文献检索结果。升级前缓存的必应词条会尝试联网刷新；刷新失败时使用现有缓存。

**窗口布局**：
```
┌──────────────────────────────────┐
│  word  [音标]  🔊美音 🔊英音  📌✕ │
│──────────────────────────────────│
│  n. 单词，词汇                     │
│  adj. 字的，文字的                 │
│──────────────────────────────────│
│  例句：                            │
│  • The word is spelled correctly. │
│    这个单词拼写正确。              │
│──────────────────────────────────│
│  来源：必应词典   [详情→]          │
└──────────────────────────────────┘
```

### 2.7 F6 - 设置中心

**设置项**：
- 取词开关（文本/图片/PDF 分别开关）
- 图片取词停留时长（默认 3 秒，1-10 秒可调）
- 翻译来源优先级配置
- 翻译窗口透明度、字号
- 快捷键配置
- 开机自启
- 生词本存储路径
- 图片 OCR 与第三方 PDF 悬停 OCR 模式互斥

### 2.8 F7 - 历史记录

- 最近查询 100 条
- 点击可重新查询
- 按时间倒序排列

### 2.9 F8 - 生词本

- 翻译浮窗和主窗口中均可加入生词本，并反馈新增、已存在或保存失败状态
- SQLite 本地存储
- 支持导出为 CSV/Anki 卡片

### 2.10 F9 - 全局热键

| 热键 | 功能 |
|------|------|
| `Ctrl+Shift+D` | 打开主窗口手动输入查询 |
| `Ctrl+Shift+T` | 切换文本取词开关 |
| `Ctrl+Shift+O` | 切换图片取词开关 |
| `Ctrl+Shift+P` | 打开内置 PDF 阅读器 |

## 3. 非功能需求

### 3.1 性能
- 常驻内存 ≤ 80MB
- CPU 空闲态 ≤ 1%
- 翻译响应时间 ≤ 1.5s（网络正常）
- OCR 识别 ≤ 800ms
- 启动时间 ≤ 2s

### 3.2 兼容性
- Ubuntu 20.04 / 22.04 / 24.04 LTS
- 同时支持 X11 和 Wayland 显示服务器
- 桌面环境：GNOME（主）、KDE、XFCE

### 3.3 可靠性
- 翻译源失败自动降级，不崩溃
- OCR 失败静默处理
- 异常自动恢复（鼠标监听断开重连）

### 3.4 隐私
- 查询历史仅本地存储
- 不上传用户查询内容到第三方（仅发送到翻译 API）
- 提供隐私模式（不记录历史）

## 4. 用户场景

### 场景 1：阅读英文网页
> 用户在 Firefox 中阅读英文技术博客，遇到生词 "ubiquitous"。
> 用鼠标选中该词 → 300ms 后翻译窗口自动弹出 → 显示"adj. 普遍存在的" → 看完点击别处，窗口消失。

### 场景 2：查看含英文的图片
> 用户用图片查看器打开一张英文架构图，遇到 "Throughput" 标签。
> 鼠标移到该词上停留 3 秒 → 自动 OCR 识别 → 弹出翻译"n. 吞吐量"。

### 场景 3：阅读英文 PDF 论文
> 用户用 Evince 打开一篇英文论文，选中 "convolutional"。
> 复用文本取词 → 弹出翻译"adj. 卷积的" + 例句。
> 对于扫描版 PDF，启用“PDF 悬停取词”，在外部阅读器中悬停取词。

### 场景 4：离线环境
> 用户在飞机上无网络，选中单词 → 必应 API 失败 → 自动降级到本地 ECDICT 词典 → 显示基础释义。
